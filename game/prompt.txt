I am making the card game setback in Rust. I have all the game logic figured out in the shared workspace. Now I need to create the GUI to make it a playable game. I started off trying Slint for the UI, but I ran into a few issues. You can see the Slint code in game/ui. I am thinking of switching to Iced for the UI since it's a native Rust UI framework. Here is the Github page for Iced: https://github.com/iced-rs/iced. Here is the documentation page for Iced: https://docs.rs/iced/latest/iced/. You may review the Slint files to see how I was previously making my UI, but I will be shortly providing instructions for how I want you to generate the Iced code.

Here is what the game should look like and how it should work:

* Main Menu
There should be a "Setback" title label. There should be the game's logo, which is CARDS_ICON in src/main.rs. There should be buttons for Singleplayer, Multiplayer, Settings, and Exit.
Clicking Singleplayer should take you to the Setup scene. It should also set the host to SingleplayerSetup and create a default GameBuilder.
Clicking Settings should take you to the Settings scene.
Clicking Exit should exit the process.
Clicking Multplayer is a little more complicated. If the player is not connected to the server, it should attempt to retrieve the user's credentials from the system. I have a function commented out that uses keyring to store the user's password securely. If the credentials cannot be retrieved, the user needs to be prompted for their credentials. There should be a popup that asks for the username and password. There should also be a login button to submit the credentials and a close button to close the popup. There also needs to be some kind of error message that indicates if the credentials are invalid or if there is a connection error. If the user was already connected, or if they were able to connect via the stored credentials, or if they were able to login by entering their credentials successfully, there should be a popup that displays multiplayer options. The options are buttons for "Create Game", "Join With Code", "Search Games", and "Close". If the player cannot connect to the server, there should be a popup that says "Cannot Connect to Server" and have a close button.
"Create Game" should take the user to the Setup scene and set the host to Host.
"Join With Code" should change the popup to prompt the user to enter a game code. The join with code popup should have an input field for the game code. There should be space for an error message if the user enters an invalid game code. There should be a button to enter the code and a button to go back to the previous popup.
"Search Games" should take you to the Multiplayer scene and change the host to Client.
"Close" should close the popup. If the function says that the game is not connected, the popup should say "Not Connected to Server". It should also call a function that returns the reason for not being connected. This reason should also be displayed. There should still be a close button at the bottom of the popup.

* Settings
Settings will be it's own scene, but you should also be able to access the settings as a popup in game. There should be a Settings component that defines the settings UI, but it should be used in the Settings scene as well as in the game's popup, which I will talk about later. The settings scene should have a Back button which takes you back to the Main Menu. The settings component should have settings listed in a column with two major sections, Audio and Keybinds. Under audio, there should be a slider for Master Volume, Music Volume, and UI Volume. Under Keybinds, there should be a subsection for Bidding. In there, there should be a keybind for "Pass", "Bid 2", "Bid 3", "Bid 4", and "Bid 5". The default keybinds should be 0, 2, 3, 4, and 5 respectively. There should be another subsection for Playing Cards. This section should have a keybind for Playing Card 1-6, where the default keybind is 1-6 respectively. There should be another subsection for Miscellaneous. In this section, there should be a keybind for toggling the settings menu in the game, which should be the escape key by default. There should be a button next to each keybind which sets it back to its default value. At the bottom of the settings component, the game's version should be displayed.

* Multiplayer
There should be a back button that takes you back to the Main Menu. Along the right side, there should be a few filter options. Each filter option should have a checkbox to indicate if it's active. The first filter should be "Team Mode" which should have a dropdown with the options "Standard" and "Custom". The second filter should be "Win by 2" which should have a checkbox to set the option. The third filter should be "Negative Scores" which should have a checkbox to set the option. The fourth filter should be "Dealer Override" which should have a checkbox to set the option. The fifth filter should be "Max Score" which should have two spin boxes. The first spin box is the lower bound and the second is the upper bound. The lower spin box should never be greater than or equal to the upper spin box. Together they represent the range of scores that can be played. The sixth filter should be "Max Players" which should have a slider to set the option. Make sure there is a label above the activation checkboxes which says "Active Filters" to indicate that the filters are active. Inactive filters should be grayed out and disabled. This means the filters need to be aligned with the label. On the left side, there should be a scroll area with rows of games. The columns should be Players (which is a fraction of number of players / max number of players), Team Mode, Win by 2, Negative Scores, Dealer Override, and Max Score. There should also be a join button on the right in each row. When the user clicks the join button, it should take you to the setup scene. On entering the multiplayer scene, you need to call a function to get the list of games from the server to be displayed.

* Setup
There should be a back button that prompts if you want to leave the game. If you click yes, it should take you back to the Main Menu. If you click no, it should close the prompt. On loading into the setup scene, you need to call a function to get the game data. The game data will contain the game settings, players, and metadata for the game. On the right, there should be a panel containing the game settings. The panel should have a title which says "Settings". The first setting should be a dropdown for Team Mode, which should have the options "Standard" and "Custom". The second setting should be a checkbox for Win by 2. The third setting should be a checkox for Negative Scores. The fourth setting should be a checkbox for Dealer Override. The fifth setting should be a spin box for Max Score. The sixth setting should be a spin box for Max Players. There should be a button at the bottom of the panel which says "Add Player". When the user clicks this button, it should take you to the player setup scene. The settings should be disabled and the Add Player button should be disabled and invisible if the player is joining someone else's multiplayer game. They should all be enabled if the player is playing a singleplayer game or if they are the host of a multiplayer game. In the center-left of the screen, there should be an ellipse of players. I have the math commented out to calculate their positions. The players are represented by the following component: an image of either PERSON_ICON or BOT_ICON depending on if the player is a human or AI. There should be an X button which removes the player from the game. There should be a username for the player. There should be a label for the Team Number with a spin box to be able to change the team number. The X button and spin box should only be enabled if the player is in singleplayer or the host of a multiplayer game. Adding and removing a player should update all player positions, and they should move to their new position. They should gradually move to the new position by animating the movement rather than just setting the new position on one frame. You should be able to drag and drop players to swap their positions around. When you pick up a player and hover it over another player, the other player should move to the dragged player's original position. When you dropped the dragged player, it should move to the open space, whether that's its original position or the position of another player that it's swapping with. In the bottom right, there should be a "Start" button. It should say "Start" in singleplayer or "Ready" in multiplayer. If in singleplayer, it will take you to the Game scene. If in multiplayer, it will put a green checkmark next to your player and the button text should change to "Unready". When all checkmarks are green, it will start a countdown from 10. You can unready by clicking the "Unready" button again, and this will stop the countdown and change the button text back to "Ready". Please put the countdown next to the ready button.

* Game
There should be a settings gear icon button in the top left corner. When clicked, it should bring up a popup with buttons for Settings, Leave Game, and Resume. Clicking Resume should close the popup. Clicking Settings should display the settings as mentioned in the Settings section. There should be a back button to get out of the settings and back to the main content in the popup. The leave game button should prompt the user to confirm if they want to leave the game. If they click yes, it should take them back to the Main Menu. If they click no, it should take them to the main content in the popup. Along the bottom, there should be labels for the round number, the scores for each team in the game, the trump suit, the lead suit for the round, the highest bid, and the username of the player that owns the pile. There should be an ellipse of players in the center of the screen. The players will still have the same images, username, and team number like before, but they should not have a team spin box, an X button, and you should not be able to drag and drop them. The player representing the local user of the game should be at the bottom of the ellipse. This player should not have the image, but should still have the team number and username. They should just have their cards displayed at the bottom of the screen. They should be able to drag and drop these cards to rearrange their order. All the players should have face-down card pictures in front of them to indicate they have cards. The middle of the ellipse should have the pile of cards that everyone plays into, and the last card played should be face up. Off to the side, there should be the remainder of the deck with the cards face down. When it's a player's turn to bid or play a card, their image should appear to glow. When it is the local user's turn to play a card, their cards should appear to glow. They should then and only then have the ability to drag and drop a card onto the center pile. There is existing logic for validating that the player played a legal card. If the player drops an illegal card onto the center pile, the card should be put back in their hand and there should be a warning that the card cannot be played. When it's the local user's turn to bid, the game should prompt the user to bid and say "Make Your Bid" and it should present buttons for Pass, 2, 3, and 4. If the dealer can override, and this player is the dealer, it should also have a 5th button. The Pass button should always be displayed when prompting, but the game should not display the buttons less than or equal to the highest bid if the highest bid is not 0. Clicking a button will end the prompt and call a function which passes the bid the player made. At the end of each round, there should be a round summary which shows which team won which points (high, low, jack and game - game should show how many game points each team earned that round). The overall score should be updated at the end of the round. When the game ends, there should be a game summary after the round summary which shows the scores of all the teams and which team won the game. There should be a button to leave the game after the game summary.
